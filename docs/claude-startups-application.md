# Claude Startups application notes

Checked October 7, 2026 against https://claude.com/programs/startups.

The current program accepts bootstrapped startups. Applicants need a Claude Console account, a company email matching the website domain, a short product description, and compliance with Anthropic's supportability policies. The published age criterion is founded in the last five years or funded in the last two. Approval is not guaranteed.

## Product description to adapt

BD2US is a public-first U.S. college application platform built for Bangladeshi students. It brings together admissions guidance, college research, funding information, application planning and an optional personal workspace. Our next feature, Ask Piku, is a personalized guidance companion designed to use Claude with BD2US's curated resources as context. We want to help students understand unfamiliar admissions terminology, compare college and funding options, and identify practical next steps, with links to sources they can verify. We do not predict admission chances or promise scholarships.

Ask Piku is in development; the Claude API integration is not live yet. API credits and technical support would help us build and evaluate source-grounded responses, including handling missing or outdated information safely.

## Before submitting

- Use founder@bd2us.com and https://bd2us.com in the application.
- Verify that the mailbox can send and receive email.
- Confirm that the domain serves the latest site over HTTPS, including `/ask`, `/about` and `/contact`.
- Sign in to the correct Claude Console organization and use the application link on the official program page.
- Supply the actual founding date, location and funding details; do not imply funding or program acceptance that has not occurred.
- Describe Piku as planned/in development, not as an existing Claude chat integration.

Changing source code does not connect DNS, update hosting domain settings, or change account-provider redirect URLs. Those hosting checks remain separate.
